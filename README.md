# Coding-Bootcamp-Database
A database for a 12-week coding bootcamp with day and night cohorts of up to 50 students. It tracks applications, enrollment, attendance, grades, payments, tutoring, and coaching, and uses constraints and triggers to enforce rules like cohort capacity, shift matching, and automatic failure after four unexcused absences.

In this repo, there is
- a final report: explaining how I researched and developed the requirements for my database model.
- coding_bootcamp.sql: the SQL scripts for the schema, sample data, triggers and queries
- coding_bootcamp.mwb: MySQL workbench model and EER diagram
